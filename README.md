# Smart-Symptom-Checker
This project is a basic health-assessment tool that allows users to enter symptoms and receive a possible matching condition along with general preventive tips. It is not a medical diagnosis tool — just an educational rule-based system for learning purposes.


🎯 Objectives

Accept user symptoms as input

Compare symptoms with predefined medical conditions

Display the condition with the highest match

Give general health suggestions

Provide a clean user interface

🧠 Features

Symptom input (comma-separated)

Rule-based condition matching

Preventive tips section

Simple and mobile-friendly UI
